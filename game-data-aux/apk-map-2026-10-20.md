## IL2CPP deep map (limitation note)
`rea analyze` on the APK needs a native provider (Ghidra/Hopper/IDA/Kuna) for
`libil2cpp.so` and the npm 6.7.0 release does not include the built-in IL2CPP metadata
decoder (repository main only). The type/method map for the game code already exists in
this repo: `decomp/Assembly-CSharp` (Il2CppDumper restored hand-inspectable sources)
and `game-data-aux/path_id_map.json`. Install Ghidra 12.1.x and set `GHIDRA_INSTALL_DIR`
if native-level decompilation of `libil2cpp.so` is needed later.
